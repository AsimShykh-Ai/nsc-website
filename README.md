# Neural Shades Creations: website design (own-brand project)

A 13-page, futuristic AI-consultancy website design built with Next.js, React, TypeScript and Tailwind. This is the free-hosting (static) edition.

- Build command: `npm run build`  → output folder: `out`
- Edit page text in `src/content/seed.json`
- Edit email/phone in `src/lib/db.ts` (replace the placeholder email)
- Contact form works on Netlify (Netlify Forms)
- Set your real address in `netlify.toml` (`SITE_URL`) after the first deploy
